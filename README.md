# L Hospital Management System

## Project Overview

L Hospital Management System is a web-based application developed using Python and Django to help manage hospital-related activities through a centralized platform. The system aims to simplify hospital administration and improve the organization of information.

## Technologies Used

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap,
- **Database:** MySQL / 
- **Version Control:** Git and GitHub

## Features

- Hospital information management
- User authentication and access control
- Management of hospital records
- Organized data storage and retrieval
- User-friendly web interface

## Installation and Setup

### 1. Clone the Repository

```bash
git clone <your-github-repository-url>
cd L-Hospital
```

### 2. Create a Virtual Environment

```bash
python -m venv venv
```

### 3. Activate the Virtual Environment

**Windows:**

```cmd
venv\Scripts\activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure the Database

Update the `DATABASES` configuration in `settings.py` according to your local database setup.

### 6. Apply Migrations

```bash
python manage.py migrate
```

### 7. Run the Development Server

```bash
python manage.py runserver
```

Open your browser and visit:

`http://127.0.0.1:8000/`
